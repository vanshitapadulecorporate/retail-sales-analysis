# retail-sales-analysis
A data analytics project focused on analyzing **retail sales, customer behavior, product performance, and shipping trends** using Python, Excel, and Power BI.

# Tools Used

* Python (Pandas, NumPy, Matplotlib, Seaborn)
* Excel
* Power BI

# Project Highlights

* Cleaned and analyzed retail sales data
* Performed exploratory data analysis
* Analyzed product and customer performance
* Created interactive Power BI dashboards
* Generated business insights from sales and shipping data

*Skills:* Data Cleaning | Data Analysis | Data Visualization | Power BI | Python | Excel
